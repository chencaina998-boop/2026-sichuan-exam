## 它的风格特点（我拆解出来的）

### 一、整体结构

```
深蓝 sticky 导航条（顶部固定）
  ↓
「模块X｜标题（编号范围）」大标题
  ↓
卡片网格（每张卡片一个知识点）
  ↓
卡片：白底 + 阴影，内容用 SVG 绘制
```

- **3 个模块**（模块1 心理学的创建 01–10｜模块2 心理学的研究对象 11–22｜模块3 感觉 23–34）
- **34 张卡片**，每张 = 一个知识点

### 二、卡片规格

| 项目 | 值 |
|---|---|
| 尺寸 | **1600 × 900**（16:9，像一页 PPT） |
| 绘制方式 | **纯 SVG 几何**（矩形 + 线条 + 文字，**没有复杂路径**） |
| 元素量 | 约 10 个 rect + 3 条 line + 18 个 text |
| 文字量 | 每张 8~18 条文本 |

### 三、配色

| 颜色 | 用途 |
|---|---|
| `#1F3A5F` | 深蓝 —— 主色（导航条、标题、边框） |
| `#E8752A` | 橙色 —— 强调（标签、重点） |
| `#FFF2E8` | 浅橙 —— 强调块底 |
| `#F5F7FA` | 浅灰 —— 内容块底 |
| `#e9edf2` | 页面背景（浅灰蓝） |
| 白色 | 卡片底 |

### 四、字号（SVG 内）

**只有三种：25 / 28 / 38** —— 极简，不搞花哨的字号层级。

### 五、每张卡片的固定字段（**这是它的精髓**）

```
#01                                          ← 编号
T3 结构树 · 心理学的创建 · 识记匹配为主（低频）  ← 卡片类型 + 主题 + 考频标注
一句话说人话：心理学从这里成为独立学科         ← 一句话（核心）
心理学创建：独立学科诞生                       ← 标题
【结构化字段】
  人物 → 冯特
  事件 → 建立世界上第一个心理实验室
  意义 → 心理学成为一门独立学科
关键词 → 心理学的创建 / 独立的科学 / 第一个心理实验室
记忆锚点 → 1人1事1意义                        ← 记忆钩子
出题人怎么考 → ...                            ← 考试视角
```

**注意几个设计**：
1. **「一句话说人话」** —— 每张卡开头一句大白话
2. **卡片类型标签**（`T1 概念卡` / `T3 结构树`）—— 一眼知道这张卡是什么形态
3. **考频标注**（`识记匹配为主（低频）`）—— 告诉考生这题重不重要
4. **「记忆锚点」** —— 记忆钩子
5. **「出题人怎么考」** —— 从出题人视角说这道题怎么考
6. **关键词** —— 圈出要记的词

## 怎么参考

### 建议参考的

- ✅ **「每张卡片一个知识点」的粒度**
- ✅ **卡片 16:9 的幻灯片感**（像一页 PPT，不是长文）
- ✅ **固定字段的套路**：编号 / 类型 / 一句话说人话 / 结构化内容 / 关键词 / 记忆锚点 / 出题人怎么考
- ✅ **深蓝 + 橙 的配色方向**
- ✅ **极简字号层级**（少数几种字号）
- ✅ **纯几何绘制**（不依赖复杂图形）
- ✅ **顶部 sticky 导航**

### 可以改进的（**不必照抄**）

- ⬜ 它没有深色模式 —— 可以加
- ⬜ 它没有交互（点选项、折叠答案）—— 可以加
- ⬜ 它没有进度记录 —— 可以加
- ⬜ 它是 34 张静态卡片，知识点之间**没有串联** —— 考生明确说想要"串成一幅画"
- ⬜ 它的「一句话说人话」很好，但**比方**较少 —— 可以加
- ⬜ 卡片之间没有"承上启下"
