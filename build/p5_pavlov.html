7.2　两种反射：先天的，和后天的

反射分两种：无条件反射和条件反射。判断只问一句：这是天生就会的，还是后来学会的？

无条件反射 · 先天（本能）

不学而会、不学而能。构成：无条件刺激（US）→ 无条件反应（UR）。

例：食物 → 分泌唾液（不分泌就噎死了，要学吗？不用）；进入眼睛的气流 → 眨眼；膝跳反射（敲膝盖下方腿就弹起来）。

「什么叫无条件刺激？你就理解为能引起无条件反应的刺激。」

条件反射 · 后天（学习）

也叫信号反射。构成：条件刺激（CS）→ 条件反应（CR）。

例：听到铃声就上课——孩子一出生听到铃声就跑到教室坐好？「怪吓人的」，这是后天学的。闹钟响就起床。

「引起条件反应的刺激叫条件刺激。」

💬
两个小提醒

① 「反应」和「反射」考试时经常混用，不用死抠区别。「他如果产生了无条件反应就代表他有了无条件反射。」
② 「闹钟响就起床」有点争议：如果是被声音吵醒，那是一回事；如果是建立了「7 点该干嘛」的闹铃意识，是另一回事。课件把它放在条件反射里，是按后一种解读。「考察的可能性不大，如果考会说得比较明确。」

无条件反射○　反应○　　刺激～～～ 反应～～～　　食物＿ 分泌唾液＿　眼睛＿ 眨眼＿　铃声＿ 上课＿

老师在反射对比框（S048）里把每个例子的刺激和反应分别划了线——这就是「先分刺激和反应」这一步的示范。

7.4　考点一：怎么结合才有用？——「要么先中性，要么和中性同时」

铃声和食物怎么结合，狗最后才会对铃声起反应？

✅ 同时出现

铃声和食物反复同时出现。「一有铃声就有食物，一有食物就有铃声。」

✅ 先中性，紧接着无条件

先给铃声，紧接着给食物。铃声像一个预告：「马上要开饭了。」

❌ 先无条件，再中性

先喂食物、吃完再摇铃——「你都吃完了，都流完哈喇子了，我再给你铃声，咋的，跳个舞消化一会儿啊？没用。」

🐔
比方：养鸡场的开饭铃

鸡场特别多的鸡，到点就打铃、放音乐——「代表马上到点吃饭了，它们就聚集在一起了」。铃声就是预告。而且必须紧接着给食物：「你响个铃声，放半天了再给食物，它也不知道俩有联系，预告就没用了。」

二级也一样：「条件刺激（铃声）和中性刺激（灯光）可以同时；或者先中性（灯光），紧接着条件刺激（铃声），紧接着食物」——灯光成了铃声的预告，铃声又是食物的预告。

老师说「这么样看起来太复杂了，怎么好记？」——不管一级二级，中性刺激要么在前，要么同时。

口诀（课件红字）要么先中性，要么和中性同时。
「考试都是考顺序。」

无条件S 和中性S ⇒ 同时　／　先中性S，紧接着无条件S
条件S 和中性S ⇒ 同时　／　先中性，紧接着条件S
要么先中性，要么…

7.6　考点三：「替代性」的无条件刺激——「作为」就是「替代」

在条件作用形成以后，条件刺激可以像无条件刺激一样诱发出有机体的反应。从这种意义上说，条件刺激似乎成了一种「替代性」的无条件刺激。（拔高：中性刺激一旦成为条件刺激，就可以作为无条件刺激）—— 课件「高级条件作用」原文（S051）

翻译成人话：以前是食物（无条件刺激）跟别人结合；现在铃声（条件刺激）跟灯光结合。在二级建立的过程中，铃声顶替了食物原来的职位——「搞起了替身文学，代替了人家的工种，串位了」。

🎭
判断题怎么反应过来

题目会「说得弯弯绕」：「中性刺激一旦成为了条件刺激，就可以作为无条件刺激。」——谁是中性刺激？刚开始的铃声。它结合久了变成条件刺激，然后可以跟别人结合了。「这个作为你就把它转换成替代的意思。」其实都是那个实验道理。

7.7　解题三步法（老师给的，全部题目通用）

  1. 先分刺激和反应。刺激是外界给的、别人给的；反应是这个个体（狗、人）做出来的行为。「你要分辨出哪个是刺激，哪个是反应。」
  2. 再分先天还是后天。先天有感觉 → 无条件刺激 / 无条件反应；后天才有感觉 → 条件刺激 / 条件反应。诀窍：反问自己「我天生就会吗？」
  3. 拔高题再往上推：它跟谁结合建立起来的？跟无条件结合 → 一级；跟条件刺激结合 → 高级。

课件上的两行提示（S064）：① 关注：先天—无条件 vs 后天—条件；② 区分：外界—刺激 vs 个体—反应。老师在两条前面各打了红勾。

7.9　真题实战 ②：拔高 1——跟「操作性」对比，看谁在前

「做不明白的原因：例子当中不会区分刺激和反应，甚至整个建立过程没联想到。」课件提示：经典性条件作用的建立 = 无条件刺激 / 条件刺激 1 + 中性刺激 → 条件反应【解题关键：S→R】。

真题 · 拔高判断
小陈一坐汽车就会晕车，并伴随着强烈的呕吐；后来他一听说要坐汽车就开始呕吐。小陈的这种反应属于操作性条件反射。
答案：B 错误
  1. 「操作性条件反射」是后面斯金纳的观点，强调反应在前、刺激在后（R→S）。一旦题目这么问，「第一反应：他应该是要拿经典来对比考」→ 那就看谁在前。
  2. 「一听到坐汽车就呕吐」：坐汽车是外在给的 → 刺激；呕吐是个体的行为 → 反应。由坐汽车引起 → 刺激在前、反应在后（S→R）。
  3. 所以不是操作性，是经典性。判断错误。（24 年考的，老师「觉得特别简单，但好多同学没整明白」。）

要坐汽车□ 呕吐□　S → R 个体　　操作性～～～ R→S　vs 经典 S→R ✓　→ B

真题 · 拔高单选
明朝的徐文长经常被叔叔无端责骂，于是他背着他人对着叔叔家的驴作揖，然后马上鞭打它。重复多次之后，驴一见他作揖，就惊跳起来。下列能解释这一现象的理论是（　）。
答案：C 经典性条件作用
  1. 驴是个体。看到作揖——外在给的 → 刺激；惊跳——驴自己的反应。刺激在前 → 经典性。「这么快就出来了。」
  2. 想细化的话，前面描述的是一个经典的建立过程：每次作揖（中性刺激）就鞭打（无条件刺激），一鞭打驴一定惊跳；重复多次后，单独作揖，驴也跳——作揖从中性刺激变成了条件刺激。
  3. 「作揖」不明白？把它理解为鞠躬。「你整不明白怎么建立，就看最后一句话，看刺激在前还是反应在前，完全能做对。」

作揖 + 鞭打 → 惊跳　×N
作揖 → 惊跳　　外界 S → 个体 R

老师在题底写的两行（S069）——正好对应实验的步骤 2 和步骤 3。

7.10　真题实战 ③：拔高 2——一级还是高级？往上推

单选 · 拔高（最难的一题）
当学生进考场或者当老师宣布即将举行考试时，学生感到非常焦虑，这可用经典条件作用理论的（　）来解释。
答案：D 高级条件作用（老师完整推导）
  1. 分刺激和反应。进考场 / 宣布考试 → 刺激；学生焦虑 → 反应。题问「用哪个理论解释」——强调的是刺激到反应的联结建立。有消退吗？消退是切断联结（光有刺激不反应了）——没有。有泛化分化吗？那要涉及两个以上相似刺激——没有。→ 排除 B、C。
  2. 先天还是后天？「我先天进考场、听到考试就焦虑吗？」→ 后天 → 条件反射的结果。
  3. 往上推：它跟谁结合才会这样？就像「我为什么对铃声流口水、对灯光流口水」——要思考结合点。「如果他进考场就成功、进考场就成功，他还焦虑吗？焦虑个毛线。」所以推断大概率是因为失败产生的焦虑：进考场 + 失败 → 焦虑，重复后 → 进考场 → 焦虑。（这个「失败」是假定的结合点。）
  4. 再问一句：失败天生就让我焦虑吗？「小孩天生失败那么多，走路跌倒、吃饭吃不进去，他难受了吗？没有。」→ 失败是后天才有感觉的 → 条件刺激。
  5. 跟条件刺激结合建立的 → 高级条件作用。选 D。「这里的失败就相当于之前的那个铃声。」

① S → R　　B⊗ C⊗
食→流　　　　　　　　　铃→流
食+铃→流　　失败→焦虑　　铃+灯→流
铃→流　　进考场+失败→焦虑　灯→流
　　　　　进考场→焦虑（条件反射）

老师在题下画了三组推导（S070→S073）：左边是一级（食→流 / 食+铃→流 / 铃→流），右边是二级（铃→流 / 铃+灯→流 / 灯→流），中间是这道题的类比（失败→焦虑 / 进考场+失败→焦虑 / 进考场→焦虑）。中间这组对应的是右边二级那组——「失败」的位置就是「铃声」。

7.11　两套信号系统：有没有「语言」

后天的条件反射，按大脑皮层功能再分两套系统。区分只看一件事：刺激是不是通过「语言」传给你的。

第一信号系统 · 人 + 动物都有

物理性的条件刺激【具体】——声、光、雷、电这种实实在在的东西。

例：狗听到铃声流口水；人听到铃声回到教室坐好。

老师的故事：巴甫洛夫做实验时「用他弟弟了」——每次给食物给铃声，他弟弟听到铃声也可以流口水。所以第一信号系统人和动物都有。

第二信号系统 · 人特有

以语言为中介的条件刺激【抽象】。

「有同学分不清声光影电，不要紧，你就看有没有『语言』这两个字。但凡通过语言给你的刺激，就是第二；不是语言给的，就是第一。」

🍰
比方：一块提拉米苏

「我今天吃了一个提拉米苏可好吃了，上面都是蓝莓，咖啡液泡的，口感有点苦涩但有些甜，甜又不腻……」同学听完叭叭流口水。刺激是老师的描述，是通过口头语言给你的 → 第二信号系统。

「语言」有几种形式（拓展延伸，看内容即可，不是让你做多选）

形式例子拆解：刺激怎么传给你
口头语言谈虎色变、谈梅生津「谈论老虎」是别人在说 → 刺激通过说话传给你；「色变 / 生津」是反应。「谈就是说话就是讨论。」
书面语言看到「虎」字就害怕「虎」这个字是写出来的 → 书面语言传递；害怕是反应。也像发微信文字描述小蛋糕让你生津。
内部言语一想到测验就焦虑大脑里想到测验——「你大脑里不是个图片吧，你大脑里是在说话吧」，会有文字、题目 → 内部言语。课后答疑：「内部语言就是大脑里叭叭讲话。」
交通语言（单独记，争议大）司机看到红灯停车红灯是刺激、停车是反应。为什么归到语言？「因为我们从小学过红灯停绿灯行黄灯等一等」，看到红灯反馈的是「停」这个意义——一种交通语言。
其他哑语、旗语等有约定意义的符号系统。

条件反射（信号反射）大圈 ⇉ 两系统

老师在核心观点页（S074 → S094）把第一信号系统例子里的「狗」圈起来、「（人+动物）」的「动物」划线——狗在第一这边；在两系统中间写了一个字（放大看像「语」），朝上指向第一信号系统的箭头打叉，朝下指向第二信号系统的箭头打勾——有语言的，不走第一，走第二；把每个语言例子的刺激和反应分别标 S、R；最后画一个大圈把「条件反射（信号反射）」圈住，画双箭头指向两系统——两套系统都在条件反射之下。

判断流程（老师的「偷机取巧」版）

① 先天还是后天？→先天本能 → 无条件反射，结束
② 后天的话，有语言吗？→有语言 → 第二没语言 → 第一
③ 主体是动物？→动物一律第一：「动物压根没有语言，它产生后天反应顶多是第一，不可能是第二。」
💡
隐藏技巧（课末老师加的）

条件反射 = 后天学习的结果。所以「如果你能判断这个是一个条件反射，能不能判断它是学习？问题不大。」比如望梅止渴是条件反射 → 它也是学习。「联动了联动了哈。」（课后有人追问「题干出现下定义」的情况，老师：大概率没问题，但具体看题目，不敢百分百保证。）

💬
课后答疑里的一问

「第一和条件可以出现在同（一道题）吗？」老师：「当然可以啦……第一和第二，它的前提不就是条件吗？咱们做题这儿前提都是条件。」——第一 / 第二信号系统都是条件反射的下位概念。

🔴 老师课末的两条铁律

① 不许加戏。「题目没说你不许给我延伸。杯弓蛇影里传递给你的就是一个影子，有说话吗？没有。你不要在这说『哎呀我大脑里想到了太可怕了』——你自己那就叫加戏。有的同学就可喜欢自己编东西了。」

② 看刺激怎么传递的，不看个体自己说了什么。「这个人他个体在这叭叭讲话有用吗？没有用。要判断第一还是第二，是要看给他这个刺激是怎么传递的，是通过语言给他的，还是通过一个图样给他的。」

7.13　两规律 ①：获得与消退——线从无到有，从有到无

获得 · 无 → 有

定义：条件刺激（如铃声）反复与无条件刺激（如食物）相匹配，使条件刺激获得信号意义的过程——条件反射建立的过程。

说白了：起初对铃声没反应 → 反复结合 → 对铃声有反应了。「从对它没有感觉到有感觉。」

消退 · 有 → ↓ / 无

定义：条件反射形成后，如果条件刺激重复出现多次而没有无条件刺激相伴随——条件反应变弱，最终消失。

说白了：光给铃声不给食物，「时间够久了，狗也不傻，你再给我铃声我就不流哈喇子了，我不跟你玩了还不行吗？」从有到少到无。

条件反射：无 → 有　　　条件反射：有 → ↓ / 无

课件上这两个框原本是空的（S076），老师讲到时才揭示答案（S080 先出「无→有」，S091 才出「有→↓/无」）。

7.14　两规律 ②：泛化与分化——分不清，和分得清

泛化 · 分不清

定义：人和动物一旦学会对某一特定的条件刺激做出条件反应以后，其他与该条件刺激相类似的刺激也能诱发其条件反应。

解题关键：相似刺激，相同反应。给铃声流口水，给口哨也流——「它分不清这两个刺激的不同」。

例：一朝被蛇咬，十年怕井绳（蛇和绳子分不清）；分不清相似的字；区分不清勇敢和鲁莽。杯弓蛇影也是——弓的倒影和蛇分不清。（还有第五站的小阿尔伯特：怕白鼠 → 怕一切白毛。）

分化 · 分得清

定义：通过选择性强化和消退，使有机体学会对条件刺激和与条件刺激相类似的刺激做出不同的反应。

解题关键：相似刺激，不同反应。怎么做？给铃声时给食物，给口哨时不给食物；反复以后「狗又聪明了」——铃声反应、口哨不反应。能分清了。

例：分辨谦让和退缩。

泛化：分不清 / 相似（对相似的反应）　蛇、绳　蛇√ 绳×
分化：分得清 / 差别（对差别的反应）　谦让○ 退缩○　互补○　盲目行动○

老师在泛化分化页（S081/S082）填的空：泛化括注「分不清」、右空补「相似」；分化括注「分得清」、右空补「差别」；右上写「蛇、绳」「蛇√ 绳×」——蛇√绳×就是分化：对蛇反应、对绳不反应。

两者在学习中互补

泛化使我们的学习从一种情境迁移到另一种情境：语文课上的高效学习方法，到英语课上也高效。
分化使我们对不同的情境作出不同的恰当反应，从而避免盲目行动：语文和英语毕竟是两个学科，有区别。

「能单独用一个吗？一个让我们把好的迁过去，一个再帮我们做适当的区分——互补，达到更好的学习效果。」

课后老师补一句：泛化、分化不是坏词，「它就是一个中性词，看怎么用」。

🎯
做题：「分得清分不清」能做七八成，剩下的用定义

「百分之七八十的题用分得清分不清都能做，但个别题目我还是希望你从定义角度解读：涉及相似刺激做相同反应 → 泛化；相似刺激做不同反应 → 分化。」比如「数学课的方法迁移到英语课」——用分得清分不清不好判，用定义一下就对上了。

单选
学生在数学课上学会了端坐在座位上认真做作业，在英语课上学生也做出类似行为。这表明学习行为存在（　）。
答案：B 泛化
  1. 数学课 → 英语课，相似情境做出类似行为 → 相似刺激、相同反应 → 泛化。
  2. 「这题直接用分得清分不清不好做，反倒从定义角度直接就对应上了。」

数学课□ 英语课□　端坐＿ 类似行为＿ → B

单选

这是课件的「笔记梳理」页（S084/S089）。老师课末带大家从头过了一遍——你也照着讲一遍，讲得出来就是真会了。

  • 🐶 经典实验：狗进食摇铃实验
  • 　├ 一级条件作用 —— 跟无条件刺激联结建立
  • 　├ 二级条件作用（高级条件作用）—— 跟条件刺激联结建立
  • 　├ 建立过程：要么先中性，要么和中性同时呈现
  • 　└ 中性 S 一旦成为条件 S，就可以作为无条件 S（= 替代）
  • 🧠 核心观点：反射
  • 　├ 无条件反射 —— 先天（本能）：无条件刺激 → 无条件反应
  • 　└ 条件反射 —— 后天（学习）：条件刺激 → 条件反应
  • 　　└ 大脑皮层功能：第一信号系统 —— 物理性（人 + 动物）；第二信号系统 —— 以语言为中介（人特有）
  • 📐 基本规律
  • 　├ 获得与消退：获得 —— 条件反射建立的过程（无→有）；消退 —— 条件反应变弱，最终消失（有→↓/无）
  • 　└ 泛化与分化（互补）：泛化 —— 相似刺激相同反应（分不清）；分化 —— 相似刺激不同反应（分得清）

章末速记 · 巴甫洛夫

  • 身份证：记忆痕迹衰退说代表；最早提出「强化」；高级神经活动学说创始人 / 生理学奠基人；狗进食摇铃实验。
  • 2 反射：无条件（先天本能，US→UR）/ 条件（后天学习，CS→CR，信号反射）。判断反问「我天生就会吗？」
  • 实验 5 步：食→流 ｜ 食+铃×N→流 ｜ 铃→流（一级）｜ 铃+灯×N→流 ｜ 灯→流（二级 / 高级）。铃声：中性 → 条件。
  • 三考点：① 顺序「要么先中性，要么和中性同时」（先无条件再中性 ❌）② 一级看跟无条件结合、高级看跟条件刺激结合 ③ 条件刺激替代了无条件刺激，「作为」= 替代。
  • 三步法：分刺激/反应（外界给的 vs 个体做的）→ 分先天/后天 → 拔高再推「跟谁结合」。巴甫洛夫永远 S→R。
  • 信号系统：先天→无条件反射结束；后天看有无语言：有→第二（口头/书面/内部/交通），无→第一；动物一律第一；不许加戏；看刺激怎么传递。
  • 4 规律：获得（无→有）· 消退（只给铃不给食，有→无）· 泛化（相似同反应，分不清，蛇绳）· 分化（相似不同反应，分得清，谦让退缩）；泛化迁移 + 分化避免盲从 = 互补。
