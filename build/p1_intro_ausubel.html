开讲之前

先把「一根线」交给你

读完这一页，后面所有的名词都有地方放。

心理学里的「学习」，说白了就一件事：脑子里两样东西之间，连上了一根线。

狗听到铃声就流口水——「铃声」和「流口水」连上了线。你看到 7×8 马上想到 56——「7×8」和「56」连上了线。猫饿了会按杠杆——「按杠杆」和「吃到鱼」连上了线。

这根线，心理学家给了一个名字：刺激—反应的联结，写成 S—R。

S = 刺激（Stimulus）

外面给你的东西。铃声、食物、老师的表扬、一道题、一个声音……凡是「别人给的、外界来的」，都是刺激。

R = 反应（Response）

你自己做出来的动作。流口水、举手、害怕、按杠杆、焦虑……凡是「个体自己做出来的」，都是反应。

🔑
整讲的万能钥匙

老师这一讲反复念叨一句话：「刺激是别人给的，反应是这个狗、这个人做出来的。」后面几乎每道题第一步都是这一句。把它记牢，你已经会了一半。

这一讲讲了什么、没讲什么

① 学习怎么分类→② 四大流派长什么样→③ 行为主义：华生 → 桑代克 → 巴甫洛夫→④ 溯源拔高

没讲到的：斯金纳、班杜拉、认知主义、建构主义、人本主义。老师原话：「斯金纳不一定讲完，班杜拉应该是进行不到了」「明天预习行为主义的后半部分，还有认知的前半部分」。所以本资料不补这些内容，只在最后交代「预告页」上出现过什么。

考频提示：老师说行为主义这一块「考频次数 76 次，高频当中的高频」；桑代克「共考查 5 次」，巴甫洛夫「共考查 8 次」。

第一站 · 学习的分类

奥苏贝尔：两个问题，四种学习

这根线是谁给你的？连上了没有？——奥苏贝尔只关心这两件事。

想象你在学一道新菜。

菜谱是别人直接塞给你的，还是你自己一次次尝出来的？——这是第一个问题，叫学习方式。

你放盐的时候，懂「盐能提鲜」所以放，还是死记「放三勺」但不知道为什么？——这是第二个问题，叫新旧知识的关系。

两个问题互不干涉：菜谱给你的也可以懂，自己试出来的也可能不懂。

关系 ↑　有 / 机　　方式 →　接 / 发

这是老师在「考点梳理」页右上角亲手画的红色坐标轴（S002）：纵轴是「关系」，上「有（意义）」下「机（械）」；横轴是「方式」，左「接（受）」右「发（现）」。两条轴互相垂直——这就是「两个维度互不依赖、彼此独立」的画面版。上图照着老师的轴重画，★ 是奥苏贝尔最提倡的那一格。

1.1　第一个问题：这根线是谁给的？（学习方式）

接受学习

内容以结论的方式呈现——老师在讲、学生在听，直接拿到结论。

✅ 效率高：成体系、有组织、有目的。老师说过，接受学习是学生学习的主要方式，就因为效率高。

❌ 忽视学生主体：学生自己积极主动发挥的空间少。

发现学习

内容不直接呈现——学生自己独立思考、独立探索、独立发现。

❌ 效率低：自己摸索，慢。

✅ 发挥主动性，以学生为主体。

🍱
比方

接受学习像外卖：饭直接送到嘴边，快，但你不会做。发现学习像自己下厨：慢、会翻车，但你真会了。

🎣
做题钩子

题干里看到「听讲解、听讲座、老师传授、背口诀表、看材料」→ 别人给的 → 接受。看到「探索、尝试错误、走迷宫、自己研究」→ 自己找的 → 发现。

1.2　第二个问题：线连上了没有？（新旧知识的关系）

什么叫「旧知识」？就是你已经有的经验。什么叫「新知识」？就是接下来要学的新材料。

机械学习

新旧建立不了联系 = 不理解。我已有的经验，理解不了新给的东西在说什么，只能死记硬背。

例：小时候背「苹果香蕉梨」、背单词，纯靠背。

有意义学习

新旧建立了联系 = 理解了。我能用已有的知识经验，理解新知识是什么意思。

而且这个联系必须是非人为的、实质性的。

🧩
比方

脑子里的旧知识像一块拼好的拼图。新知识来了，能咔哒一声嵌进去，就是有意义学习；怎么都嵌不上、只能摆在旁边硬记，就是机械学习。

⚠️ 整讲最容易错的一个点：什么叫「非人为」

有意义学习要求的联系，必须是知识本身内在就有的。你自己硬编出来的联系，不算。

✅ 本身有联系 → 有意义

你学过三角形，现在学四边形。四边形能拆成两个三角形，是二倍关系——这是知识内在的联系，你用旧经验理解了新知识。

❌ 人为赋予 → 不算有意义（算机械）

为了记圆周率 3.1415926，编「山巅一寺一壶酒」。数字本身没这个意思，是你硬编的。老师说：「人为赋予的情况它不算。」

意义学习 → 有联系—理解 ／ ×联系 人为赋予　　意义识记　　3.1415926　　△ ▱ 2　旧→新

老师在 2020 年真题页（S006）右下画了分叉：「意义学习」分两支——「有联系—理解」和「×联系·人为赋予」，下面另写了「意义识记」；又在分类汇总表（S009）右侧画了一个三角形、一个带对角线的四边形，写了「2」和「旧→新」，旁边写着 3.1415926。意思是：编口诀属于「意义识记」（记忆方法里的一种），但不属于奥苏贝尔的「有意义学习」。

编口诀 · 谐音记忆 · 打油诗 = 人为赋予 → 判机械

1.3　先机械，后有意义

人的学习顺序是：先机械，后有意义。小时候背苹果香蕉梨、背单词都是死记硬背，后来慢慢能理解它说的是什么了。老师在 PPT 上用红字补了「先机械 / 后有意义」（S002 右侧）。

1.4　必背四句话（老师说「考试就考这个判断」）

  1. 两个维度互不依赖、彼此独立。接受学习既可以是机械的，也可以是有意义的；发现学习也一样。它们可以交叉，也都可以独立。
  2. 四种学习相互交叉，无高低级之分。发现学习能发挥独立性，就更高级吗？——并非如此。
  3. 奥苏贝尔提倡「有意义的接受学习」。
  4. 每个学者强调的不一样：后面会学到布鲁纳，他强调「发现」更重要。问谁，就答谁的。

1.6　顺手复习：学习的定义、什么算学习

做题时老师带着大家回顾了两句：

学习的定义：个体（人、机器、动物）在一定条件下，凭借经验或练习（反复经验）产生的行为或行为潜能的比较持久的变化。

关键词是「行为或行为潜能」——不是只有看得见的行为。你今天态度变了、情感变了（特别爱一个人了但不表现出来），别人观察不到，这也是学习。所以「学习是可观察的行为变化」这句话太窄，是错的。

什么不算学习：膝跳反射是本能；疲劳后动作变形、暗适应是生理现象——都不是学习。背诵唐诗才是学习。

1.7　真题实战（老师原版推导）

解题两步：第一步看谁给的（接受/发现），第二步看懂不懂（机械/有意义）。做完自己点选项，再看解析。

判断定义识记
从实质上说，接受学习即机械学习，发现学习即意义学习。
答案：B 错误
  1. 老师：「接受就机械吗？发现就有意义吗？不对，它们彼此独立。」
  2. 接受学习可以机械也可以有意义，发现学习同样。两个维度互不依赖。

  1. 「听老师的讲解」→ 别人给的 → 接受，所以「发现学习」直接判错。

章末速记 · 奥苏贝尔

  • 两个问题：谁给的（接受/发现）× 连上没（机械/有意义）。两轴垂直，互不依赖。
  • 有意义 = 用旧经验理解新知识，联系必须非人为、实质性；编口诀、谐音、打油诗 = 人为赋予 = 机械。
  • 先机械后有意义；四种学习无高低；奥苏贝尔提倡有意义的接受学习（布鲁纳提倡发现）。
  • 接受学习效率高但忽视主体，是学生学习的主要方式；发现学习效率低但以学生为主体。
  • 学习的定义：凭经验或练习产生的行为或行为潜能的持久变化——内隐的变化也算。
