桑代克：一只饿猫，自己试出一根线

老师说：「桑代克东西不多——一实验、三规律、一评价。」

一只饿猫被关进笼子，笼子外面放着一条鱼。

猫想吃，就到处乱抓乱咬——这叫盲目尝试。偶然一次，它碰到了杠杆，门开了，它跑出去吃到了鱼。

再关进去，它还是乱试。但试了很多次以后，犯错越来越少，开笼子越来越快。最后——一进去就直接按杠杆。

桑代克说：学习就是这样试错出来的。所以叫试误说。

6.1　先回忆：桑代克是谁（讲前回顾）

老师先带大家回忆了第二章学过的内容，再补了两个新地位。

方面内容记法

老师的小故事（帮你记「动物」）

「人丑多读书的代表人物」：桑代克长得不太好看，追美女追不到，在爱情上吃了不少苦，于是潜心研究。当时又规避用人做实验（伦理问题），他「被逼没招了」，选择用动物——于是成了最早用动物做研究、动物心理学的开创者、美国动物心理学实验室创始人之一。

6.2　一实验：猫开笼取食实验

这个实验有四个名字，考试可能换着叫：

猫开笼取食实验饿猫实验迷笼实验迷箱实验

「迷笼 / 迷箱」是翻译版本不同，笼子箱子没区别。说「迷箱」时后面斯金纳用得更多，但桑代克这个也可以叫迷箱，「这个你要清楚」。

为什么猫一定要「饿」？

「如果它不饿，关笼子里它会在里边睡大觉，没有觅食的欲望、没有觅食的动机。」饿 → 想吃 → 想开笼子。「饿」是实验的前提条件——这就是后面「准备律」的来源。

前提：猫→饥饿 → 觅食动机　　（猫）按杠杆 → 食物　　R → S　√

老师在实验图（S020）上写的三条：「前提：猫→饥饿→…动机」；「按杠杆→食物」，按杠杆下面标 R、食物下面标 S，并在标题「试误说」旁写 R→S √。意思是：桑代克的实验里，反应（按杠杆）在前，刺激（食物）在后。

谁在前，谁在后？

刺激是别人给的——食物是刺激；反应是猫自己做的——按杠杆是反应。猫先按杠杆、后得到食物，所以桑代克的实验是反应在前、刺激在后（R→S）。

但他说「刺激—反应的联结」这句话本身没有强调谁前谁后，就是「联合在一起」的意思。老师再次叮嘱：这里不要和加涅的第二级对比，分开记。

学习曲线：为什么这条线一直往下走

纵轴是猫逃出笼子所需的时间，横轴是尝试次数（0 → 24）。从 160 秒 → 40 秒 → 20 秒……随着尝试次数增加，用时越来越少。

一开始不会 → 用时多；练多了，错误减少 → 用时少；最后「一进去我饿了我就打开」→ 学会了。这条下降的曲线，就是「学习发生了」的证据。

时间　渐进　次数　160○　0○　～～（一条平滑的下降线）

老师在曲线旁标了「时间」「次数」，圈了 160 和原点，另外叠画了一条平滑的下降曲线——原图的黑折线有局部起伏，她想让你看的是总体趋势往下。

6.3　核心观点三条（对应实验一步一步得出）

  1. 学习的实质：形成联结。谁和谁的联结？外界的刺激和反应的联结。猫最后学会的，就是「按杠杆—得食物」这根线。
  2. 联结怎么建立：通过试误。「盲目尝试 → 逐步减少错误（试误）→ 再尝试」反复作用。
  3. 试误受什么支配：三条学习公律——准备律、练习律、效果律。

另外一条：动物学习是盲目的；人的学习是有意识的（动物的学习无须以观念为媒介）。

形成联结（刺激—反应）　通过试误 → 公律　　动物：本能　人：自我调控…　　R→S

6.4　三规律：一根线连得牢不牢，看三件事

猫试错的过程，被什么影响？桑代克总结出三条「学习的公律」。用你自己学习来想：

准备律 · 想不想学

学之前，你有没有「想学」的状态？——动机。

练习律 · 练不练

练就熟、不练就废。——用 or 不用。

效果律 · 有没有反馈

练完了有人告诉你对不对吗？——反馈。最重要。

🚗
老师的亲身比方

「我去考驾照练车，怎么练教练都不告诉我正确与否，我就越练越懵越练越懵。所以我急需要反馈，我问这个问那个得到了反馈，我进步就特别快。」——光练、光有心理准备，不告诉你对错，你还是成功不了。所以效果律最重要。

① 准备律（law of readiness）

定义：学习前的预备性反应 / 预备定势（生理 + 心理）→ 属于动机范畴。「我提前做好心理准备，做好预备反应，有一种心理上的启动状态，知道接下来要干嘛。」

生理角度：猫饥饿 → 想觅食 → 这就是开笼子的动机（虽然从生理解读，但属于动机范畴）。
心理角度：提前告诉你今天上两个半小时、讲到哪，「我要听明白它我才能上岸」——心理有准备，也是动机。

老师的解释：有准备 + 学习活动满足了它 → 高兴、满意；没任何准备就上来给活动 → 不高兴、痛苦。「就像我没吃饱饭，我就不想去听课。」

教育启示：不能搞突袭。「7 点上课，7 点前你要做好各种准备：提前预习、上好厕所、吃好饭，然后你可以更积极地去听课。」

🔴 准备律最容易错的一句话（老师：「打起精神，仔细听」）

「桑代克讲的准备不是指学习前的知识准备或成熟方面的准备，而是指学习者在学习开始时的预备定势，属于动机范畴。」

这句话怎么考？要分两个角度解题：

① 定义角度

问：「桑代克说的准备等不等于知识准备、成熟？」→ 不等同。

注意：并不是说知识准备、成熟达不到准备律的效果，只是桑代克没从这个角度说——他强调的是动机角度：不管你做什么准备，引起了动机才属于准备律。

② 例子角度

问：「老师让学生预习、复习旧知、查找资料，属于什么律？」→ 准备律！

为什么？因为预习、复习、查资料，「最后的落脚点都是引起学习动机、提高学习积极性」。我预习过了、旧知识和新知识有联系、我好奇怎么联系——我就想学了。所以「例子分析题你就不需要区分那么多，管他什么方面的准备，能引起学习动机的都叫准备律。」

桑代克的准备 ≠ 学习前的知识准备或成熟方面的准备
桑代克的准备 → 预备定势，属于学习动机范畴
预习 / 复习有关等 → 调动学习积极性 → 符合准备律

这是「易错辨析」页（S032/S033）左下角的三条红字结论，老师在「预习」上画了大圈，在「身心基础」旁写了「生理」。三条一起背，第一条防定义题、第三条防例子题。

教材截图上的依据（S032 右下）

教材原文说：个体在学习上的准备工作包括两方面——一为身心基础（例如学武术，先看身体发育是否正常、四肢关节是否敏捷、反应是否灵活、眼手是否协调——老师：「你这些特别棒，你学起来就更积极；腿脚不利索，你就说我不想学、我不行」→ 身体状况决定有没有动机）；二为学习动机（求知欲和好奇心是提高学习动机的重要因素；一般引起学习动机，包括复习上次所学内容、以及有关资料，以便对新教材产生兴趣，从而调动学习积极性）。「不管预习还是复习，都是为了提前做好准备，接下来接受新知识更方便。」

② 练习律

定义：已形成的联结，重复反应 → 联结增强；不重复 → 联结减弱。猫不是一次就学会开笼子，是反复开、反复开才减少了错误（熟能生巧）。

应用律

常用（练习）→ 联结 ↑

失用律

不常用（不练习）→ 联结 ↓（用进废退）

「练习律其实就是用和不用的关系。」你平时解题反复练，一看到题就能想到怎么解；不练就忘了。

教育启示：在学习过程中以及学习结束后，都应该不断地加强练习。

③ 效果律（最重要）

定义：正或负的反馈 → 加强或减弱联结。

满意律

满意的后果 → 行为频率 ↑。「你每次练，加油你最棒你真优秀，情绪价值、各种奖励满满当当」→ 愿意做，行为频率提得高高的。猫逃出去吃到鱼——食物就是它满意的反馈，下次还继续。

烦恼律

烦恼的后果 → 行为频率 ↓。「一学习我就骂你、否定你、各种挑刺批评打压」→ 越来越烦，行为频率下降。猫逃出去没鱼、「甚至是拖狗屎」→ 不愿意做了。

教育启示：使学生的学习达到自我满意的积极结果，防止一无所获的消极结果。「管他是鼓励还是精神价值，你都给他上一上。」

三律关系 · 必背效果律是最重要的学习定律；准备律和练习律是效果律的附律 / 从属律。
——没有它，另两条「意义性也不大」。

用 or 不用　　反馈○　获得食物○　　最重要＿　准备律和练习律＿　效果律＿

老师在三公律树状图（S027/S029）上：练习律旁写「用 or 不用」；效果律里圈了「反馈」和猫例子的「获得食物」；右栏「最重要」「准备律和练习律」「效果律」三处加线强调。

6.6　动物学习 vs 人类学习

最早的实验是用动物做的：猫盲目尝试错误。后来研究人，发现人不一样——「你把人关笼子里，他不小心按到杠杆开了门，下次还会盲目尝试吗？不会。人进去会先观察环境、去思考，尝试到了按到杠杆，下次就会了，不会有那么多错误。」

结论（一般考判断）动物的学习是盲目的；人的学习是有意识的。（动物的学习无须以观念为媒介）
⚠️
两个不要弄混

① 三条公律是人和动物共有的。「不要因为前面一直在说动物，你就忽视了人也受这三个公律的影响。」
② 老师的延伸：桑代克早期研究忽略了认知、忽视了人学习的目的性——猫真的一点意识都没有吗？不见得。这就是早期研究受到诟病、批判的原因——「很多理论站在当时的角度上并不够完善」。

6.7　一评价（两条，都从好的角度说）

  1. 联结—试误说是教育心理学史上第一个较为完整的学习理论。（老师：「还可以加『全』——完整的学习理论。」）
  2. 它的提出，对于教育心理学成为一门独立学科是有促进意义的。（因为他开创了实验室、用数据做出了科学的研究。）

「三天不听耳生，三天不读口生。」在语言学习上，听和说是非常重要的，如果想让学生的英语水平不断提高，每天的听和说是必不可少的。这体现了桑代克学习定律中（　）。
答案：A 练习律
  1. 不听耳生、不读口生 → 必不可少的重复练、多次练 → 练习律。「外界给予结果了吗？没有，光说它进行练。」
单选 · 易错
桑代克曾做过一个实验：被试者被要求蒙上眼睛后练习画 4 英寸长的线段，经过 3000 多次练习，毫无进步，对该试验的结果最适当的解释是（　）。
答案：C
  1. 为什么 3000 次练习毫无结果？没有反馈。桑代克正是用这个实验说明反馈的重要性、说明效果律为什么最重要。
  2. 反馈可以怎么得来？两条路：① 自己看——如果不蒙眼，他能看到画歪了、画长了；② 别人说——别人告诉他。
  3. C「不知道自己的练习结果」= 两条路都包含了，更全面；D「主试未评价」只说了「别人没告诉」，忽略了他自己也看不到（因为蒙了眼），太片面。「C 比较全面，D 比较片面。」

蒙上眼睛○　多次练习毫无进步＿　C：练习结果○ → 反馈
没有反馈 → 自己看○ ✓＋ ／ 别人给 ✓　　眼看可以…　别人说—可以…

老师在题旁画了分叉（S036→S040 逐步补全）：「没有反馈」分「自己看」和「别人给」两支，两支都打了勾还加了「+」号——C 选项把两支都包住了。
