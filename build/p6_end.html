经典性 vs 操作性：同一根线，两个方向

这一页在视频 156:41，是课件给「学有余力」的同学做的「溯源拔高」。老师课上没有展开讲，这里只按课件原文整理。

回头看这一讲的两只动物：

🐶 巴甫洛夫的狗：先来铃声，再流口水——外界先给，个体后反应。S → R。

🐱 桑代克的猫：先按杠杆，再得到鱼——个体先做，结果后来。R → S。

两根线都是「刺激—反应的联结」，实质相同；但方向相反，建立过程有差异。

8.1　三条结论（课件原文）

  1. 桑代克和斯金纳的学习理论从性质上看都属于操作性条件反射。（都是先做出动作，再得到结果：R→S。）
  2. 经典性条件理论和操作性条件作用理论的实质相同（S—R / 刺激和反应的联结）。
  3. 经典条件反射的建立过程与操作条件反射的建立过程存在差异（S→R vs R→S）。
经典性条件作用（巴甫洛夫）操作性条件作用（桑代克 / 斯金纳）
顺序S → R：刺激在前，反应在后R → S：反应在前，刺激（结果）在后
实验狗进食摇铃：先摇铃再给食猫开笼取食 / 斯金纳箱：先按杠杆再得食
怎么判断外界先给了什么，个体才反应个体先做了什么，才得到结果
共同点实质都是刺激与反应的联结（S—R）

第五站说「行为主义的 S—R 没有箭头」，就是因为它把两种方向都包进去了。第六站猫的板书 R→S、第七站狗的板书 S→R，到这里合成一句话：实质相同，方向不同。真题里「小陈坐汽车呕吐」「徐文长的驴」都是用这个方向做出来的。

8.2　四道判断（课件原题；老师课上未逐题讲，解析按课件三条结论推）

判断 · 拔高
操作性条件反射理论强调行为前的强化。
答案：B 错误
  1. 操作性是 R→S：先有行为（按杠杆），之后才有结果（食物）。强化在行为之后，不是之前。
判断 · 拔高
桑代克和斯金纳的学习理论从性质上看都属于操作性条件反射。
答案：A 正确
  1. 课件结论一原文。两人都是 R→S。
判断 · 拔高
经典条件反射的建立过程与操作条件反射的建立过程无根本差异。
答案：B 错误
  1. 建立过程存在差异：一个 S→R，一个 R→S，方向反了。
判断 · 拔高
经典性条件理论和操作性条件作用理论的实质相同。
答案：A 正确
  1. 实质都是 S—R 联结。注意和上一题区分：实质相同（对）、建立过程有差异（也对）。问什么答什么。

9.1　考场上的五把钥匙（老师教的解题步骤）

  1. 先读题，再判考点。「一道题上来第一件事读题，读完了再判断考察哪个知识点。」
  2. 分刺激 / 反应。外界给的是刺激，个体做的是反应。落脚点问谁答谁。
  3. 分先天 / 后天。「我天生就会吗？」先天 = 无条件 / 本能；后天 = 条件 / 学习。
  4. 看谁在前。刺激在前 → 经典（巴甫洛夫）；反应在前 → 操作（桑代克 / 斯金纳）。
  5. 看关键词。预习复习→准备律；反复练→练习律；表扬批评成绩→效果律；不知不觉→内隐；热爱之情→态度；方法技巧→认知策略；有语言→第二；动物→第一；相似同反应→泛化；相似不同反应→分化；编口诀→机械。

并且：不许加戏。题目没说的，不要自己延伸。
