开讲之前

先把「一根线」交给你

读完这一页，后面所有的名词都有地方放。

心理学里的「学习」，说白了就一件事：脑子里两样东西之间，连上了一根线。

狗听到铃声就流口水——「铃声」和「流口水」连上了线。你看到 7×8 马上想到 56——「7×8」和「56」连上了线。猫饿了会按杠杆——「按杠杆」和「吃到鱼」连上了线。

这根线，心理学家给了一个名字：刺激—反应的联结，写成 S—R。

S = 刺激（Stimulus）

外面给你的东西。铃声、食物、老师的表扬、一道题、一个声音……凡是「别人给的、外界来的」，都是刺激。

R = 反应（Response）

你自己做出来的动作。流口水、举手、害怕、按杠杆、焦虑……凡是「个体自己做出来的」，都是反应。

🔑
整讲的万能钥匙

老师这一讲反复念叨一句话：「刺激是别人给的，反应是这个狗、这个人做出来的。」后面几乎每道题第一步都是这一句。把它记牢，你已经会了一半。

第一站 · 学习的分类

奥苏贝尔：两个问题，四种学习

这根线是谁给你的？连上了没有？——奥苏贝尔只关心这两件事。

想象你在学一道新菜。

菜谱是别人直接塞给你的，还是你自己一次次尝出来的？——这是第一个问题，叫学习方式。

你放盐的时候，懂「盐能提鲜」所以放，还是死记「放三勺」但不知道为什么？——这是第二个问题，叫新旧知识的关系。

两个问题互不干涉：菜谱给你的也可以懂，自己试出来的也可能不懂。

关系 ↑　有 / 机　　方式 →　接 / 发

这是老师在「考点梳理」页右上角亲手画的红色坐标轴（S002）：纵轴是「关系」，上「有（意义）」下「机（械）」；横轴是「方式」，左「接（受）」右「发（现）」。两条轴互相垂直——这就是「两个维度互不依赖、彼此独立」的画面版。上图照着老师的轴重画，★ 是奥苏贝尔最提倡的那一格。

1.1　第一个问题：这根线是谁给的？（学习方式）

接受学习

内容以结论的方式呈现——老师在讲、学生在听，直接拿到结论。

✅ 效率高：成体系、有组织、有目的。老师说过，接受学习是学生学习的主要方式，就因为效率高。

❌ 忽视学生主体：学生自己积极主动发挥的空间少。

发现学习

内容不直接呈现——学生自己独立思考、独立探索、独立发现。

❌ 效率低：自己摸索，慢。

✅ 发挥主动性，以学生为主体。

🍱
比方

接受学习像外卖：饭直接送到嘴边，快，但你不会做。发现学习像自己下厨：慢、会翻车，但你真会了。

🎣
做题钩子

题干里看到「听讲解、听讲座、老师传授、背口诀表、看材料」→ 别人给的 → 接受。看到「探索、尝试错误、走迷宫、自己研究」→ 自己找的 → 发现。

1.2　第二个问题：线连上了没有？（新旧知识的关系）

什么叫「旧知识」？就是你已经有的经验。什么叫「新知识」？就是接下来要学的新材料。

机械学习

新旧建立不了联系 = 不理解。我已有的经验，理解不了新给的东西在说什么，只能死记硬背。

例：小时候背「苹果香蕉梨」、背单词，纯靠背。

有意义学习

新旧建立了联系 = 理解了。我能用已有的知识经验，理解新知识是什么意思。

而且这个联系必须是非人为的、实质性的。

🧩
比方

脑子里的旧知识像一块拼好的拼图。新知识来了，能咔哒一声嵌进去，就是有意义学习；怎么都嵌不上、只能摆在旁边硬记，就是机械学习。

⚠️ 整讲最容易错的一个点：什么叫「非人为」

有意义学习要求的联系，必须是知识本身内在就有的。你自己硬编出来的联系，不算。

✅ 本身有联系 → 有意义

你学过三角形，现在学四边形。四边形能拆成两个三角形，是二倍关系——这是知识内在的联系，你用旧经验理解了新知识。

❌ 人为赋予 → 不算有意义（算机械）

为了记圆周率 3.1415926，编「山巅一寺一壶酒」。数字本身没这个意思，是你硬编的。老师说：「人为赋予的情况它不算。」

意义学习 → 有联系—理解 ／ ×联系 人为赋予　　意义识记　　3.1415926　　△ ▱ 2　旧→新

老师在 2020 年真题页（S006）右下画了分叉：「意义学习」分两支——「有联系—理解」和「×联系·人为赋予」，下面另写了「意义识记」；又在分类汇总表（S009）右侧画了一个三角形、一个带对角线的四边形，写了「2」和「旧→新」，旁边写着 3.1415926。意思是：编口诀属于「意义识记」（记忆方法里的一种），但不属于奥苏贝尔的「有意义学习」。

编口诀 · 谐音记忆 · 打油诗 = 人为赋予 → 判机械

1.3　先机械，后有意义

人的学习顺序是：先机械，后有意义。小时候背苹果香蕉梨、背单词都是死记硬背，后来慢慢能理解它说的是什么了。老师在 PPT 上用红字补了「先机械 / 后有意义」（S002 右侧）。

1.4　必背四句话（老师说「考试就考这个判断」）

  1. 两个维度互不依赖、彼此独立。接受学习既可以是机械的，也可以是有意义的；发现学习也一样。它们可以交叉，也都可以独立。
  2. 四种学习相互交叉，无高低级之分。发现学习能发挥独立性，就更高级吗？——并非如此。
  3. 奥苏贝尔提倡「有意义的接受学习」。
  4. 每个学者强调的不一样：后面会学到布鲁纳，他强调「发现」更重要。问谁，就答谁的。

1.6　顺手复习：学习的定义、什么算学习

做题时老师带着大家回顾了两句：

学习的定义：个体（人、机器、动物）在一定条件下，凭借经验或练习（反复经验）产生的行为或行为潜能的比较持久的变化。

关键词是「行为或行为潜能」——不是只有看得见的行为。你今天态度变了、情感变了（特别爱一个人了但不表现出来），别人观察不到，这也是学习。所以「学习是可观察的行为变化」这句话太窄，是错的。

什么不算学习：膝跳反射是本能；疲劳后动作变形、暗适应是生理现象——都不是学习。背诵唐诗才是学习。

  • 两个问题：谁给的（接受/发现）× 连上没（机械/有意义）。两轴垂直，互不依赖。
  • 有意义 = 用旧经验理解新知识，联系必须非人为、实质性；编口诀、谐音、打油诗 = 人为赋予 = 机械。

第二站 · 学习的分类

加涅：一个货架，一段台阶

老师说「第一节比较有挑战的是加涅」。其实他只分了两次：一次按「学完得到什么」，一次按「线有多复杂」。

加涅把学习分了两次，这两次的目的完全不同——一次是平放的，一次是往上爬的。

分类一 · 学习结果（5 类，无高低）

像超市的五个货架，平级摆放。问的是：学完以后你得到了什么？

分类二 · 学习水平（8 级，从低到高）

像八级台阶，一级一级往上。问的是：这根线连得有多复杂？考试会考顺序。

⚠️
最爱考的区别

学习结果分类没有高低之分；学习水平分类从低到高。课后答疑老师又说了一遍：「学习水平分类都是从低到高的哈，加涅结果分类没有高低问题。」

级怎么理解老师的例子
1 信号学习刺激在前，反应在后。先来一个信号，我再反应。狗听到铃声流口水（铃声先来）
2 刺激—反应学习反应在前，刺激在后，而且只有一个行为反应。你举手（一个动作），我表扬你
3 连锁学习一连串动作连起来。用钥匙开锁：掏钥匙 → 对准锁眼 → 扭钥匙，好几个动作
4 言语联想学习不是动作层面，是语言层面连成串。词一、词二、词三，组成一句话
5 辨别学习做基础的区分：外在形状大小，或两个易混的东西。这两个单词特别容易混，我把它俩区分开
6 概念学习比辨别复杂：要抓共同本质特征；而且加涅认为最终结果是能运用概念——能识别、能归类。所有鸟有什么特征；把属于马的、属于植物的各归一类

2.3　三组最易混，一句话分清

信号 vs 刺激—反应

只看谁在前：刺激先来 = 信号；反应先做 = 刺激—反应。

刺激—反应 vs 连锁

看几个动作：一个动作（举手）= 刺激—反应；一串动作（开锁、体操）= 连锁。

辨别 vs 概念

辨别是简单区分；概念要抓共同本质，还要能运用、能归类。

心理学刚诞生时，大家研究的是意识——你脑子里在想什么。

问题是：意识看不见、摸不着、说不清道不明，实验很难验证。

华生站出来说：别研究那些虚的，我只看外面能看见的行为。在实验里给你一个刺激，看你做出什么反应——这才叫科学，能精确测量。

于是一大批人跟着他走。这就是行为主义的诞生。

5.2　小阿尔伯特实验（恐惧泛化实验）

桑代克：一只饿猫，自己试出一根线

老师说：「桑代克东西不多——一实验、三规律、一评价。」

一只饿猫被关进笼子，笼子外面放着一条鱼。

猫想吃，就到处乱抓乱咬——这叫盲目尝试。偶然一次，它碰到了杠杆，门开了，它跑出去吃到了鱼。

再关进去，它还是乱试。但试了很多次以后，犯错越来越少，开笼子越来越快。最后——一进去就直接按杠杆。

桑代克说：学习就是这样试错出来的。所以叫试误说。

6.2　一实验：猫开笼取食实验

这个实验有四个名字，考试可能换着叫：

猫开笼取食实验饿猫实验迷笼实验迷箱实验

「迷笼 / 迷箱」是翻译版本不同，笼子箱子没区别。说「迷箱」时后面斯金纳用得更多，但桑代克这个也可以叫迷箱，「这个你要清楚」。

为什么猫一定要「饿」？

「如果它不饿，关笼子里它会在里边睡大觉，没有觅食的欲望、没有觅食的动机。」饿 → 想吃 → 想开笼子。「饿」是实验的前提条件——这就是后面「准备律」的来源。

前提：猫→饥饿 → 觅食动机　　（猫）按杠杆 → 食物　　R → S　√

老师在实验图（S020）上写的三条：「前提：猫→饥饿→…动机」；「按杠杆→食物」，按杠杆下面标 R、食物下面标 S，并在标题「试误说」旁写 R→S √。意思是：桑代克的实验里，反应（按杠杆）在前，刺激（食物）在后。

谁在前，谁在后？

刺激是别人给的——食物是刺激；反应是猫自己做的——按杠杆是反应。猫先按杠杆、后得到食物，所以桑代克的实验是反应在前、刺激在后（R→S）。

但他说「刺激—反应的联结」这句话本身没有强调谁前谁后，就是「联合在一起」的意思。老师再次叮嘱：这里不要和加涅的第二级对比，分开记。

学习曲线：为什么这条线一直往下走

纵轴是猫逃出笼子所需的时间，横轴是尝试次数（0 → 24）。从 160 秒 → 40 秒 → 20 秒……随着尝试次数增加，用时越来越少。

6.3　核心观点三条（对应实验一步一步得出）

  1. 学习的实质：形成联结。谁和谁的联结？外界的刺激和反应的联结。猫最后学会的，就是「按杠杆—得食物」这根线。

6.4　三规律：一根线连得牢不牢，看三件事

猫试错的过程，被什么影响？桑代克总结出三条「学习的公律」。用你自己学习来想：

准备律 · 想不想学

学之前，你有没有「想学」的状态？——动机。

练习律 · 练不练

练就熟、不练就废。——用 or 不用。

效果律 · 有没有反馈

练完了有人告诉你对不对吗？——反馈。最重要。

老师的亲身比方

「我去考驾照练车，怎么练教练都不告诉我正确与否，我就越练越懵越练越懵。所以我急需要反馈，我问这个问那个得到了反馈，我进步就特别快。」——光练、光有心理准备，不告诉你对错，你还是成功不了。所以效果律最重要。

① 准备律（law of readiness）

定义：学习前的预备性反应 / 预备定势（生理 + 心理）→ 属于动机范畴。「我提前做好心理准备，做好预备反应，有一种心理上的启动状态，知道接下来要干嘛。」

生理角度：猫饥饿 → 想觅食 → 这就是开笼子的动机（虽然从生理解读，但属于动机范畴）。
心理角度：提前告诉你今天上两个半小时、讲到哪，「我要听明白它我才能上岸」——心理有准备，也是动机。

老师的解释：有准备 + 学习活动满足了它 → 高兴、满意；没任何准备就上来给活动 → 不高兴、痛苦。「就像我没吃饱饭，我就不想去听课。」

教育启示：不能搞突袭。「7 点上课，7 点前你要做好各种准备：提前预习、上好厕所、吃好饭，然后你可以更积极地去听课。」

🔴 准备律最容易错的一句话（老师：「打起精神，仔细听」）

「桑代克讲的准备不是指学习前的知识准备或成熟方面的准备，而是指学习者在学习开始时的预备定势，属于动机范畴。」

这句话怎么考？要分两个角度解题：

① 定义角度

问：「桑代克说的准备等不等于知识准备、成熟？」→ 不等同。

注意：并不是说知识准备、成熟达不到准备律的效果，只是桑代克没从这个角度说——他强调的是动机角度：不管你做什么准备，引起了动机才属于准备律。

② 例子角度

问：「老师让学生预习、复习旧知、查找资料，属于什么律？」→ 准备律！

为什么？因为预习、复习、查资料，「最后的落脚点都是引起学习动机、提高学习积极性」。我预习过了、旧知识和新知识有联系、我好奇怎么联系——我就想学了。所以「例子分析题你就不需要区分那么多，管他什么方面的准备，能引起学习动机的都叫准备律。」

桑代克的准备 ≠ 学习前的知识准备或成熟方面的准备
桑代克的准备 → 预备定势，属于学习动机范畴
预习 / 复习有关等 → 调动学习积极性 → 符合准备律

② 练习律

定义：已形成的联结，重复反应 → 联结增强；不重复 → 联结减弱。猫不是一次就学会开笼子，是反复开、反复开才减少了错误（熟能生巧）。

应用律

常用（练习）→ 联结 ↑

失用律

不常用（不练习）→ 联结 ↓（用进废退）

「练习律其实就是用和不用的关系。」你平时解题反复练，一看到题就能想到怎么解；不练就忘了。

教育启示：在学习过程中以及学习结束后，都应该不断地加强练习。

③ 效果律（最重要）

定义：正或负的反馈 → 加强或减弱联结。

满意律

满意的后果 → 行为频率 ↑。「你每次练，加油你最棒你真优秀，情绪价值、各种奖励满满当当」→ 愿意做，行为频率提得高高的。猫逃出去吃到鱼——食物就是它满意的反馈，下次还继续。

烦恼律

烦恼的后果 → 行为频率 ↓。「一学习我就骂你、否定你、各种挑刺批评打压」→ 越来越烦，行为频率下降。猫逃出去没鱼、「甚至是拖狗屎」→ 不愿意做了。

教育启示：使学生的学习达到自我满意的积极结果，防止一无所获的消极结果。「管他是鼓励还是精神价值，你都给他上一上。」

三律关系 · 必背效果律是最重要的学习定律；准备律和练习律是效果律的附律 / 从属律。
——没有它，另两条「意义性也不大」。

6.6　动物学习 vs 人类学习

最早的实验是用动物做的：猫盲目尝试错误。后来研究人，发现人不一样——「你把人关笼子里，他不小心按到杠杆开了门，下次还会盲目尝试吗？不会。人进去会先观察环境、去思考，尝试到了按到杠杆，下次就会了，不会有那么多错误。」

结论（一般考判断）动物的学习是盲目的；人的学习是有意识的。（动物的学习无须以观念为媒介）
⚠️
两个不要弄混

① 三条公律是人和动物共有的。「不要因为前面一直在说动物，你就忽视了人也受这三个公律的影响。」
② 老师的延伸：桑代克早期研究忽略了认知、忽视了人学习的目的性——猫真的一点意识都没有吗？不见得。这就是早期研究受到诟病、批判的原因——「很多理论站在当时的角度上并不够完善」。

7.2　两种反射：先天的，和后天的

反射分两种：无条件反射和条件反射。判断只问一句：这是天生就会的，还是后来学会的？

无条件反射 · 先天（本能）

不学而会、不学而能。构成：无条件刺激（US）→ 无条件反应（UR）。

例：食物 → 分泌唾液（不分泌就噎死了，要学吗？不用）；进入眼睛的气流 → 眨眼；膝跳反射（敲膝盖下方腿就弹起来）。

「什么叫无条件刺激？你就理解为能引起无条件反应的刺激。」

条件反射 · 后天（学习）

也叫信号反射。构成：条件刺激（CS）→ 条件反应（CR）。

例：听到铃声就上课——孩子一出生听到铃声就跑到教室坐好？「怪吓人的」，这是后天学的。闹钟响就起床。

「引起条件反应的刺激叫条件刺激。」

💬
两个小提醒

① 「反应」和「反射」考试时经常混用，不用死抠区别。「他如果产生了无条件反应就代表他有了无条件反射。」
② 「闹钟响就起床」有点争议：如果是被声音吵醒，那是一回事；如果是建立了「7 点该干嘛」的闹铃意识，是另一回事。课件把它放在条件反射里，是按后一种解读。「考察的可能性不大，如果考会说得比较明确。」

翻译成人话：以前是食物（无条件刺激）跟别人结合；现在铃声（条件刺激）跟灯光结合。在二级建立的过程中，铃声顶替了食物原来的职位——「搞起了替身文学，代替了人家的工种，串位了」。

题目会「说得弯弯绕」：「中性刺激一旦成为了条件刺激，就可以作为无条件刺激。」——谁是中性刺激？刚开始的铃声。它结合久了变成条件刺激，然后可以跟别人结合了。「这个作为你就把它转换成替代的意思。」其实都是那个实验道理。

7.7　解题三步法（老师给的，全部题目通用）

  1. 先分刺激和反应。刺激是外界给的、别人给的；反应是这个个体（狗、人）做出来的行为。「你要分辨出哪个是刺激，哪个是反应。」
  2. 再分先天还是后天。先天有感觉 → 无条件刺激 / 无条件反应；后天才有感觉 → 条件刺激 / 条件反应。诀窍：反问自己「我天生就会吗？」
  3. 拔高题再往上推：它跟谁结合建立起来的？跟无条件结合 → 一级；跟条件刺激结合 → 高级。

课件上的两行提示（S064）：① 关注：先天—无条件 vs 后天—条件；② 区分：外界—刺激 vs 个体—反应。老师在两条前面各打了红勾。

7.10　真题实战 ③：拔高 2——一级还是高级？往上推

单选 · 拔高（最难的一题）

答案：D 高级条件作用（老师完整推导）
  1. 分刺激和反应。进考场 / 宣布考试 → 刺激；学生焦虑 → 反应。题问「用哪个理论解释」——强调的是刺激到反应的联结建立。有消退吗？消退是切断联结（光有刺激不反应了）——没有。有泛化分化吗？那要涉及两个以上相似刺激——没有。→ 排除 B、C。

7.11　两套信号系统：有没有「语言」

后天的条件反射，按大脑皮层功能再分两套系统。区分只看一件事：刺激是不是通过「语言」传给你的。

第一信号系统 · 人 + 动物都有

物理性的条件刺激【具体】——声、光、雷、电这种实实在在的东西。

例：狗听到铃声流口水；人听到铃声回到教室坐好。

老师的故事：巴甫洛夫做实验时「用他弟弟了」——每次给食物给铃声，他弟弟听到铃声也可以流口水。所以第一信号系统人和动物都有。

第二信号系统 · 人特有

以语言为中介的条件刺激【抽象】。

「有同学分不清声光影电，不要紧，你就看有没有『语言』这两个字。但凡通过语言给你的刺激，就是第二；不是语言给的，就是第一。」

🍰

「我今天吃了一个提拉米苏可好吃了，上面都是蓝莓，咖啡液泡的，口感有点苦涩但有些甜，甜又不腻……」同学听完叭叭流口水。刺激是老师的描述，是通过口头语言给你的 → 第二信号系统。

形式例子拆解：刺激怎么传给你

7.13　两规律 ①：获得与消退——线从无到有，从有到无

获得 · 无 → 有

定义：条件刺激（如铃声）反复与无条件刺激（如食物）相匹配，使条件刺激获得信号意义的过程——条件反射建立的过程。

说白了：起初对铃声没反应 → 反复结合 → 对铃声有反应了。「从对它没有感觉到有感觉。」

消退 · 有 → ↓ / 无

定义：条件反射形成后，如果条件刺激重复出现多次而没有无条件刺激相伴随——条件反应变弱，最终消失。

说白了：光给铃声不给食物，「时间够久了，狗也不傻，你再给我铃声我就不流哈喇子了，我不跟你玩了还不行吗？」从有到少到无。

条件反射：无 → 有　　　条件反射：有 → ↓ / 无

课件上这两个框原本是空的（S076），老师讲到时才揭示答案（S080 先出「无→有」，S091 才出「有→↓/无」）。

7.14　两规律 ②：泛化与分化——分不清，和分得清

泛化 · 分不清

定义：人和动物一旦学会对某一特定的条件刺激做出条件反应以后，其他与该条件刺激相类似的刺激也能诱发其条件反应。

解题关键：相似刺激，相同反应。给铃声流口水，给口哨也流——「它分不清这两个刺激的不同」。

例：一朝被蛇咬，十年怕井绳（蛇和绳子分不清）；分不清相似的字；区分不清勇敢和鲁莽。杯弓蛇影也是——弓的倒影和蛇分不清。（还有第五站的小阿尔伯特：怕白鼠 → 怕一切白毛。）

分化 · 分得清

定义：通过选择性强化和消退，使有机体学会对条件刺激和与条件刺激相类似的刺激做出不同的反应。

解题关键：相似刺激，不同反应。怎么做？给铃声时给食物，给口哨时不给食物；反复以后「狗又聪明了」——铃声反应、口哨不反应。能分清了。

例：分辨谦让和退缩。

泛化：分不清 / 相似（对相似的反应）　蛇、绳　蛇√ 绳×
分化：分得清 / 差别（对差别的反应）　谦让○ 退缩○　互补○　盲目行动○

老师在泛化分化页（S081/S082）填的空：泛化括注「分不清」、右空补「相似」；分化括注「分得清」、右空补「差别」；右上写「蛇、绳」「蛇√ 绳×」——蛇√绳×就是分化：对蛇反应、对绳不反应。

两者在学习中互补

泛化使我们的学习从一种情境迁移到另一种情境：语文课上的高效学习方法，到英语课上也高效。
分化使我们对不同的情境作出不同的恰当反应，从而避免盲目行动：语文和英语毕竟是两个学科，有区别。

「能单独用一个吗？一个让我们把好的迁过去，一个再帮我们做适当的区分——互补，达到更好的学习效果。」

课后老师补一句：泛化、分化不是坏词，「它就是一个中性词，看怎么用」。

做题：「分得清分不清」能做七八成，剩下的用定义

「百分之七八十的题用分得清分不清都能做，但个别题目我还是希望你从定义角度解读：涉及相似刺激做相同反应 → 泛化；相似刺激做不同反应 → 分化。」比如「数学课的方法迁移到英语课」——用分得清分不清不好判，用定义一下就对上了。

单选
学生在数学课上学会了端坐在座位上认真做作业，在英语课上学生也做出类似行为。这表明学习行为存在（　）。
答案：B 泛化
  1. 数学课 → 英语课，相似情境做出类似行为 → 相似刺激、相同反应 → 泛化。
  2. 「这题直接用分得清分不清不好做，反倒从定义角度直接就对应上了。」

数学课□ 英语课□　端坐＿ 类似行为＿ → B

单选
经典条件作用理论认为，有机体学会对某一特定的条件刺激做出条件反应以后，类似的刺激也能诱发该条件反应。这一现象称为（　）。
答案：C 泛化
  1. 「类似的刺激也能诱发」→ 相似做相同 → 泛化。这题几乎就是定义原文。
单选
狗最初对圆形和椭圆形做出同样的反应，经训练后仅对圆形做出该反应，这都是条件反射的（　）。
答案：D 分化
  1. 「一定要看到后面」：经训练后仅对圆形反应——椭圆还反应吗？不反应 → 能分清它俩不一样了 → 分化。
  2. 前半句「最初做出同样反应」是泛化，但题问的是训练后的结果。

经典性 vs 操作性：同一根线，两个方向

这一页在视频 156:41，是课件给「学有余力」的同学做的「溯源拔高」。老师课上没有展开讲，这里只按课件原文整理。

回头看这一讲的两只动物：

🐶 巴甫洛夫的狗：先来铃声，再流口水——外界先给，个体后反应。S → R。

🐱 桑代克的猫：先按杠杆，再得到鱼——个体先做，结果后来。R → S。

两根线都是「刺激—反应的联结」，实质相同；但方向相反，建立过程有差异。

8.1　三条结论（课件原文）

  1. 桑代克和斯金纳的学习理论从性质上看都属于操作性条件反射。（都是先做出动作，再得到结果：R→S。）
  2. 经典性条件理论和操作性条件作用理论的实质相同（S—R / 刺激和反应的联结）。
  3. 经典条件反射的建立过程与操作条件反射的建立过程存在差异（S→R vs R→S）。
经典性条件作用（巴甫洛夫）操作性条件作用（桑代克 / 斯金纳）
顺序S → R：刺激在前，反应在后R → S：反应在前，刺激（结果）在后
实验狗进食摇铃：先摇铃再给食猫开笼取食 / 斯金纳箱：先按杠杆再得食
怎么判断外界先给了什么，个体才反应个体先做了什么，才得到结果
共同点实质都是刺激与反应的联结（S—R）

9.1　考场上的五把钥匙（老师教的解题步骤）

  1. 先读题，再判考点。「一道题上来第一件事读题，读完了再判断考察哪个知识点。」
  2. 分刺激 / 反应。外界给的是刺激，个体做的是反应。落脚点问谁答谁。
  3. 分先天 / 后天。「我天生就会吗？」先天 = 无条件 / 本能；后天 = 条件 / 学习。
  4. 看谁在前。刺激在前 → 经典（巴甫洛夫）；反应在前 → 操作（桑代克 / 斯金纳）。
  5. 看关键词。预习复习→准备律；反复练→练习律；表扬批评成绩→效果律；不知不觉→内隐；热爱之情→态度；方法技巧→认知策略；有语言→第二；动物→第一；相似同反应→泛化；相似不同反应→分化；编口诀→机械。

并且：不许加戏。题目没说的，不要自己延伸。
